# 🎓 estudos — TUTOR pessoal (João Lucas)

Repositório dedicado ao tutor de estudos com IA. Leva o aluno do zero ao nível
avançado, um passo de cada vez, com registro completo de progresso.

**Tópicos:** Medicina & Saúde · Inglês (acadêmico p/ congressos) · Alemão (hobby).
**Foco atual:** intensivo de ECG + Anestesia & Sedação.

## Como usar
Abra o repositório com um agente de código (Claude Code etc.) e diga **`aprender`**.
O tutor lê `CLAUDE.md` (seu manual), decide se é hora de revisar ou avançar
(Consolidation Gate) e conduz a lição.

## Estrutura
- `CLAUDE.md` — manual operacional do TUTOR.
- `curriculum/` — roadmap (`ROADMAP.md`) e estágios (`stages/`).
- `progress/` — `progress.json` (estado), `DASHBOARD.md`, `skill-tree.md`.
- `flashcards/` — baralho + fila de revisão (SM-2-lite).
- `logs/` — registro de cada sessão + `INDEX.md`.
- `review/` — pontos fracos + `CONSOLIDATION-GATE.md`.
- `feynman/` · `exercises/` · `assessments/` · `playground/` · `visuals/` · `media/`.
